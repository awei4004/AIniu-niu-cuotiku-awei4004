# 阶段四：图片 OCR 录入

## 1. 已完成流程

```text
拍照/相册选图 → 校验并上传原图 → OCR 识别 → 编辑识别文本 → 保存错题 → 详情查看原图
```

录入页复用阶段二的错题表单。OCR 文本始终先作为候选结果显示，用户点击“确认校对并填入题目”后才进入题目字段；用户可以直接修改题目或在识别失败时手动保存。

## 2. 页面行为

| 场景 | 行为 |
| --- | --- |
| 拍照 | 调用微信 `chooseMedia` 选择相机，限制一张图片 |
| 相册 | 调用微信 `chooseMedia` 选择相册，限制一张图片 |
| 图片校验 | 仅接受 JPG/PNG，单张不超过 5 MB，并校验文件头和实际字节数 |
| 图片路径 | 先通过文件系统校验内容，再保存到用户持久目录，最后解码和预览；不直接加载开发者工具的 `http://tmp/` 地址 |
| 本地演示 | 将图片保存到本地，使用明确标记的演示识别结果，不声称是真实 OCR |
| 云端运行 | 上传到微信云存储，云函数调用腾讯云 OCR `GeneralBasic` |
| 识别结果 | 可编辑，确认后才写入题目；原图引用同时保存 |
| 识别失败 | 保留原图和失败任务，允许手动录入；点击新建请求可重新识别 |
| 网络中断 | 保存识别任务编号，重新打开表单可查询原任务，避免重复调用 |
| 详情查看 | 仅当前用户可以获取临时原图地址，点击原图可预览 |
| 加载失败 | 显示错误并提供重新加载；录入页保留上传重试、识别和移除入口，不清空已输入的题目 |

暂不把手写字、复杂公式、竖式、分数和几何图形识别作为验收条件。图片中包含的姓名、学校等信息应先裁剪；外部识别前云端模式会显示确认提示。

## 3. 数据与接口

新增 `files` 集合，`tasks` 集合继续记录 OCR 任务。

### files

保存当前用户、请求编号、格式、大小、状态、云文件路径、内容摘要和创建时间。状态为 `pending → ready`。本地演示模式使用本地持久文件路径；云端模式保存微信云文件 ID。

### tasks

OCR 任务保存 `fileId`、学科、请求编号、服务商、状态、识别结果或失败信息、截止时间和更新时间。状态为 `running → completed / failed`。同一用户相同请求编号会返回原任务；不同文件或学科复用请求编号会被拒绝。

### 接口

| 接口 | 作用 |
| --- | --- |
| `file.register` | 登记待上传图片，检查格式和大小 |
| `file.complete` | 校验上传路径与图片内容，完成原图登记 |
| `file.access` | 校验归属并返回本地路径或临时访问地址 |
| `ocr.recognize` | 创建或恢复 OCR 任务，返回候选文本或失败状态 |
| `task.get` | 查询 OCR 任务，超时任务会被标记失败 |
| `question.create/update` | 保存原图引用和已校对的 OCR 任务引用 |

图片、任务和错题都由服务端根据当前用户校验归属。错题保存必须满足原图已上传完成；绑定 OCR 任务时必须与原图一致并明确提交了校对结果。

## 4. 真实 OCR 配置

默认 `miniprogram/config/env.js` 中 `cloudEnvId` 为空，使用本地演示模式。云端部署时，在云函数环境变量中配置：

```text
OCR_PROVIDER=tencent
TENCENT_SECRET_ID=腾讯云 SecretId
TENCENT_SECRET_KEY=腾讯云 SecretKey
TENCENT_OCR_REGION=ap-guangzhou
TENCENT_SESSION_TOKEN=可选的临时凭证 Token
```

密钥只放在云函数环境变量中，不写入小程序前端或代码仓库。需要为腾讯云账号开通 OCR 服务，并为云函数配置访问外网的能力。当前适配器使用服务端签名调用腾讯云 OCR；未配置 `OCR_PROVIDER` 或密钥时，云端会返回“尚未配置 OCR”，原图仍可保留并手动录入。

云开发环境还需要创建 `files` 集合，并保留阶段一至三的 `users`、`students`、`wrong_questions`、`generated_questions`、`practice_records`、`tasks` 集合。运行以下命令同步共享校验规则后，再部署云函数：

```powershell
npm.cmd run build
```

## 5. 手动验收

1. 在本地演示模式打开“录入错题”，点击拍照或从相册选择一张 JPG/PNG 图片。
2. 检查图片预览和上传进度，点击“演示识别”。
3. 修改识别文本，点击“确认校对并填入题目”，再保存错题。
4. 返回错题详情，确认能够查看并点击预览原图。
5. 选择一张超过 5 MB 的图片，确认上传前提示失败。
6. 选择语文或数学图片，关闭或模拟识别失败，确认原图仍保留且可以手动填写题目保存。
7. 使用真实云环境，配置 OCR 变量后重复上述流程，确认结果标记为“识别完成 · 待校对”。
8. 更换另一个用户，尝试使用前一个用户的图片 ID、任务 ID 和错题 ID，确认均不能读取或绑定。
9. 在网络中断后重新打开同一表单，查询原任务，确认不会重复生成 OCR 任务。
10. 在 Windows 微信开发者工具重新编译后，从相册重新选择图片，确认不再出现 `http://tmp/` 重定向导致的图片 CORS 错误；保存后重新打开详情检查原图。旧页面尚未完成上传的临时图片应重新选择，无需清空全部错题数据。

游客模式下 `wx.operateWXData` 的受限及模拟返回提示，与上述图片路径错误分开检查；正式微信能力需要使用自己的小程序 AppID 验证。
