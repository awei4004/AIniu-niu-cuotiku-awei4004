# 真实 AI 出题接入

## 当前交付状态

已实现服务端真实 AI 调用适配器、结构校验、请求去重、超时任务恢复和页面模式标识。尚未配置实际服务商、模型、API Key 和云环境，也未发起真实付费 API 请求；自动化测试使用模拟响应。

本地模式继续使用演示模板。真实 AI 必须通过云函数调用；设置云环境 ID 后，本地学生和错题不会自动迁移，需要在云端重新创建。

## 支持的接口

供应商需要提供 HTTPS Chat Completions 兼容接口，支持非流式请求、Bearer API Key、system/user 消息，以及 `choices[0].message.content` 文本响应和 `finish_reason=stop`。

`AI_BASE_URL` 填供应商的基础地址，适配器会追加 `/chat/completions`。例如基础地址 `https://YOUR_PROVIDER_HOST/v1` 对应完整请求地址 `https://YOUR_PROVIDER_HOST/v1/chat/completions`；不要把完整路径重复填入基础地址。

当前不包含 Responses、原生 Claude/Gemini 协议或图片理解接口。如供应商仅提供其他协议，需要新增对应适配器。

## 云函数环境变量

在 `cloudfunctions/api` 对应云函数的环境变量中设置；不要写入小程序前端或提交密钥到仓库。

| 变量 | 必填 | 值或含义 |
| --- | --- | --- |
| `AI_PROVIDER` | 是 | `openai-compatible` |
| `AI_BASE_URL` | 是 | 供应商 HTTPS 基础地址，通常含 `/v1`，不含 `/chat/completions` |
| `AI_MODEL` | 是 | 供应商实际开放给该账户的模型 ID |
| `AI_API_KEY` | 是 | API Key，只存放在服务端 |
| `AI_TIMEOUT_MS` | 否 | 默认 `45000`，范围 `1000` 至 `60000` |
| `AI_MAX_TOKENS` | 否 | 默认 `4096`，范围 `256` 至 `16000`，需结合模型输出上限调整 |
| `AI_TOKEN_PARAMETER` | 否 | 默认 `max_tokens`；模型要求新参数时设为 `max_completion_tokens` |
| `AI_RESPONSE_FORMAT` | 否 | 默认 `json_object`；不支持该参数的接口可设 `text`，省略 response_format，仍执行 JSON 校验 |

缺少或错误配置时显示“AI 待配置”，不会自动降级成演示出题。仅在明确设置 `AI_PROVIDER=demo` 时，云端才使用模板并显示“演示出题”。“AI 出题”表示配置字段齐全，不代表认证和模型权限已经验证。

## 部署步骤

1. 使用自己的小程序 AppID 和云开发环境，创建 `users`、`students`、`wrong_questions`、`generated_questions`、`practice_records`、`tasks`、`files` 集合。数据库仍通过云函数访问。
2. 在 `miniprogram/config/env.js` 中填写 `cloudEnvId`。
3. 设置上述云函数环境变量，确认云函数能通过 HTTPS 访问供应商地址。
4. 将云函数执行超时配置为覆盖 AI 请求和数据库写入的时长，建议为 90 秒以上；以实际云环境支持值为准，若上限更低，应相应减小 `AI_TIMEOUT_MS` 并实测。
5. 运行 `npm.cmd run build`，上传并部署 `cloudfunctions/api`，选择云端安装依赖。此次没有增加第三方依赖，但要包含新增的 `generation-service.js` 和现有 PDF 字体资源。
6. 重新编译小程序，打开一条错题的“生成同类题”，确认顶部显示“AI 出题”。
7. 先生成 1 道数学题，再检查语文题；人工确认题目、答案和解析后再练习。

## 联通测试

根目录新增 `npm.cmd run verify:ai`。它读取当前终端进程的上述环境变量，实际发起一次付费请求，用示例数学错题生成 1 道题，并校验响应结构。它不连接微信数据库，不能代替云端和微信端验收。

先在当前终端安全配置服务地址、模型和密钥，再运行：

```powershell
npm.cmd run verify:ai
```

未配置时命令会失败并说明缺少真实 AI 配置，不会用演示结果冒充测试成功。命令不打印请求头、密钥或题目全文。

## 数据、质量与任务行为

- 发送学科、年级、章节、题型、题目、原答案、学生答案、解析、错误原因和知识点；数据库 ID、学生昵称字段、OpenID 和原图地址不作为请求字段发送。题目等文本如果本身含个人信息，仍需要先人工清理。
- 每次生成 1 至 3 道，服务端检查字段长度、数量、难度和重复题，结果保存为 `draft`；不能自动确认后直接发给学生。
- 数学单个数值答案可按现有规则判定；语文、应用题、选择题和非单数值答案采用家长判定。结构校验不能证明答案和教学内容正确，仍需人工确认。
- 页面按一次出题保存一个请求编号，重复请求复用已有任务；相同编号用于其他原题、来源版本或参数时拒绝。
- 请求中断时保存编号并显示“查询原任务”。重新进入同一错题页面会恢复查询；查不到任务时复用原编号重新提交，不创建新的请求编号。
- AI HTTP 默认超时 45 秒，客户端出题调用超时配置为 75 秒，出题任务截止时间为 90 秒。任务超时后查询会标记失败，迟到结果不能发布。
- 明确失败后，用户再次点击生成会创建新请求，可能产生新的费用；不存在自动循环重试。
- 目前只有单次题量、请求去重和超时限制，尚无完整的用户日配额或消费账本。面向多人开放前需补充额度控制。

## 常见错误

| 错误 | 检查方向 |
| --- | --- |
| `AI_NOT_CONFIGURED` | 四个必填变量、HTTPS 地址、超时和参数取值 |
| `AI_AUTH_FAILED` | API Key、账户权限、模型权限 |
| `AI_RATE_LIMITED` | 账户额度和并发/频率限制 |
| `AI_CONFIG_ERROR` | 基础地址、模型名、JSON 模式、token 参数兼容性 |
| `AI_PROVIDER_FAILED` | 云函数外网、供应商可用性、连接中断 |
| `AI_TIMEOUT` | 查询原任务，确认状态；必要时减少题量或调整模型与超时 |
| `INVALID_AI_OUTPUT` | JSON/字段/题量/难度错误、重复题、拒绝生成或输出截断 |
| `SOURCE_CHANGED` | 原题在生成期间已修改，需要按新内容重新生成 |

## 手动验收

1. 数学：输入 `23 × 14 =`，选择三年级、一般难度、1 道，检查新题不重复原题且答案正确。
2. 语文：输入近反义词或句子练习，检查生成题适龄、有参考答案及解析，提交后由家长判定。
3. 生成后先编辑再确认，验证未确认题不能练习。
4. 模拟生成请求断网，恢复网络后查询原任务，确认只保留一批结果。
5. 使用另一个用户查询任务 ID 或生成题 ID，确认无法访问。
6. 检查错误配置、无额度、输出截断时的反馈，确认原错题数据不受影响。
