# PDF Font

NotoSansSC-VF.ttf is the Simplified Chinese Noto Sans SC variable TrueType font.
The checked-in build is copied from the Windows Noto Sans SC distribution for local PDF compatibility.
Source project: https://github.com/notofonts/noto-cjk

Keep the font and license when deploying this cloud function.
